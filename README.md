# 💻 Galeria de um Programador

Atividade prática de HTML e CSS solicitada pela professora **Samira Gabriely**, da disciplina de Introdução à Computação.

## 📋 Sobre a atividade

O objetivo do exercício foi desenvolver uma galeria de mídias utilizando HTML e CSS, trabalhando com imagens, vídeos, áudios e o sistema de Grid Layout.

### Requisitos solicitados

- **Grid Layout** com pelo menos 3 colunas
- No mínimo **2 imagens**
- No mínimo **2 vídeos**
- No mínimo **2 áudios**
- Cada mídia acompanhada de uma descrição utilizando `<figcaption>`
- Estilização utilizando:
  - Bordas
  - Cores
  - Fontes
  - Espaçamentos

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid Layout
- Google Fonts — JetBrains Mono
- YouTube Embed

## 📁 Estrutura do projeto

```text
├── index.html
├── style.css
└── assets/
    └── images/
        ├── code.jpg
        └── setup.jpg
```

## 💻 Como visualizar

Basta clonar o repositório e abrir o arquivo `index.html` no navegador:

```bash
git clone <url-do-repositorio>
cd <nome-do-repositorio>
```

Depois é só abrir o arquivo `index.html`.
